# Universal YSWS Guidelines

This folder mirrors the shared [YSWS Project Submission Guidelines](https://hackclub.gitbook.io/ysws-project-submission-guidelines/BLBRN8LIfoCZhFV6oMNR/ysws-project-submission-guidelines) used as the baseline for Macondo reviews.

Macondo's program-specific docs under `docs/` override these guidelines when they conflict.

Refresh the checked-in mirror manually:

```sh
bun run docs:refresh:ysws
```
