# macondo-checker

[Privacy Policy](./PRIVACY.md)

## running

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

Set `EXA_API_KEY` to let reviews verify public demo listings that block normal
HTTP clients with Cloudflare or other bot protection.
